## 需要修改

1. **1965H2 event**：“台湾海军接连失利”→“**国民党海军接连失利**”（或“台湾当局海军”）。依据：大陆通行表述称东山、乌坵海战中的对方为“国民党海军”，用“台湾海军”有把台湾当作独立政治实体之嫌。
2. **1954H1 / 1960H1 / 1966H1 / 1972H1 event**：“由‘国民大会’续任”“再续任”只写“续任”而没有宾语，读者不知道续任什么职务。建议统一写成“**由所谓‘国民大会’再次选为‘总统’**”（1954H1）、“**再次连任‘总统’**”（其余三条），引号不能省。依据：README 自定的规则是 1949 年后涉及这些称谓都要加引号；1960 年以后的连任依据是“动员戡乱时期临时条款”，大陆史著一般写作“连任‘总统’”。
3. **1922H2 milestone.subtitle**：“在珠江舰上随侍孙中山四十余日”→“**在永丰舰上随侍孙中山四十余日**”。依据：舰名是永丰舰（1925 年改名中山舰），停泊在珠江白鹅潭；S3 魏雅丽文、维基“永丰舰”都这样写。
4. **1922H2 milestone.quote.source**：“孙中山《孙大总统广州蒙难记》序（1922年）”→“**孙中山为蒋介石《孙大总统广州蒙难记》所作序（1922年）**”。依据：该书由蒋介石撰写，孙中山作序（S3）。原写法容易被理解为孙中山的著作。
