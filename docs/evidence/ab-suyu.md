## 2. 史实（独立核查，权威来源优先，只有维基百科一个出处的按“存疑”）

| 指标 | 甲 | 乙 |
|---|---|---|
| 里程碑：正确 / 存疑 / 错误 | 19 / 1 / 0（共 20） | 25 / 1 / 0（共 26） |
| 旁白关键陈述：正确 / 存疑 / 错误 | 52 / 1 / 0（共 53） | 49 / 8 / 1（共 58） |
| 旁白存疑率 | 1.9% | 13.8% |
| 引文逐字可查 | 2 / 2 | 2 / 5 |
| 1958 批判、1994 平反表述 | 准确 | 准确 |

- 乙唯一的错误：“1946 年 7 月全面内战爆发”（应为 6 月下旬，错到了另一个半年）。
- 乙的存疑主要集中在引文上：
  - 《七律·抒怀》首尾拼接，没有标省略；
  - 毛泽东复电删节，没有标省略；
  - “粟裕立了第一功”只见于晚年回忆；
  - 庐山表态无法逐字核到。
- 甲唯一的存疑：“龙冈反‘围剿’”的地点（红 64 师当时主要在东韶方向）。

结论：两部都没有里程碑级硬伤；甲的旁白明显更克制、更可靠，乙信息量大，但用了较多弱来源。

## 5. 局限

- 只有一个人物、每组只跑一次，结论是方向性的。
- 盲评并不完全：两组的画面风格和目录结构差异明显，评审代理有可能猜出组别。评审规则已禁止它们读取交付说明和日志。
- 记忆索引、全局 CLAUDE.md 会注入两组的会话，无法屏蔽；这些内容与视频方法无关。
- 带 skill 的组在交付之后，往 skill 的 `pitfalls.md` 里追加了一条规则；这发生在成片完成后，不影响它的结果。
- 从零组也能联网查资料；两组都没有读到粟裕的专著原书。

## 8. 评测后的修复（2026-11-03）

评测暴露出 5 个 skill 层面的问题，已在 lives 修复，并同步到 skill 模板（`fb63019`、`b5ec8f9`、`7aa51cd`）：

| 问题 | 原因 | 修复 |
|---|---|---|
| 121 s 近景里有一条两端都不在画内的竖线 | 旧轨迹按视频秒数衰减：早年每步只占 0.55 s，1927 年南下潮汕的南北直线到这里才过了约 20 s，几乎没有变暗 | 改为按“走过了几个半年步”衰减，时间常数近景 3 步、全景 12 步，亮度下限近景 0.08、全景 0.3 |
| 赴莫斯科那段画面像在青藏上空乱飞，也看不到“图外”标注 | 镜头只跟着人物小点；图外代理点和它的标注都在画外 | 到过图外地点的那一步镜头拉远（视距 3200–5400）；图外标注贴到画面安全区边缘；超出画面的注记整条隐藏；当前位置落进 HUD 区时不画 |
| 淮海里程碑：镜头停在碾庄，旁白先讲济南 | 同一半年里有两件大事，旁白先讲了不在镜头里的那件 | narration.md 加规则“里程碑旁白第一句从镜头所停的地点讲起”，审片清单加对应检查项；粟裕旁白已改写 |
| 成片为全范围 yuvj420p / pc，部分播放器和平台会偏色 | 截图帧是全范围 BT.601，`-pix_fmt yuv420p` 没有真正转换范围 | 总装时转成标准范围 BT.709 并写明色彩标签；`check_outputs --require` 检查 yuv420p/tv/bt709 |
| “史载”条长文字被截断 | 只允许一行显示 | 最多两行；章节卡说明文字改为均衡换行 |

另外修了一个模板缺陷：命令行报错测试写死了用 `sushi`，在没有苏轼数据的项目里必然失败，改为对项目实际存在的人物测试。

重渲结果：lives 六部与粟裕全部重渲，`check_outputs --require` 七部都通过，包括新加的色彩检查。粟裕评测时的原片另存为 `ab/skill/suyu-trajectory/粟裕_人生轨迹_AB评测版.mp4`。
