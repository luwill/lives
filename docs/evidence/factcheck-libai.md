## 需要修改

1. **736H2 note 与 contested“诗文系年”中的《将进酒》条**
   - 现文：“开元二十四年（安旗）／天宝十一载（郁贤皓等）”
   - 应改为：“约开元二十四年（郁贤皓《李白集》）／开元二十二年（管士光《李白诗集新注》）／天宝十一载（黄锡珪《李太白编年诗集目录》）”
   - 依据：古诗文网《将进酒》创作背景栏转引郁贤皓、黄锡珪原说；多条检索结果的说法相同。安旗的系年未能在线核实，建议删去“安旗”，或标明“待核”。
   - 另外，事件中的“秋”和“南返经襄阳再会孟浩然”只有 S9 支持，建议在 note 中注明“月份与襄阳之行据安旗体系年谱（S9），未见他证”。

2. **730H1 event：“谒张说父子”**
   - 应改为：“初夏首入长安，欲谒张说未果（张说时病，同年十二月卒），结识其子卫尉卿张垍；寓终南山玉真公主别馆”
   - 依据：郁贤皓据《玉真公主别馆苦雨赠卫尉张卿》考定首入长安，并与张九龄《张说墓志》参证（刘畅文、郁胡文）。

3. **758H1 note 与 contested“诗文系年”**
   - 在 contested“诗文系年”的 views 中增补一条：“《与史郎中钦听黄鹤楼上吹笛》：乾元元年流放途中（安旗体系）／乾元二年遇赦东归时（王琦）”
   - note 改为：“此诗系年有乾元元年流放途中、乾元二年遇赦后两说，此从前说，见 contested”
   - 依据：王谱乾元二年条明言“與史郎中飲聽黄鶴樓上吹笛詩…是遇赦以後之作”；赵庆伟文同此说。

4. （建议，非错误）**701H1 event**：改为“生于西域碎叶；史载母梦长庚星，因名白，字太白”，以示诞生异兆出自序碑和史传的记载。
