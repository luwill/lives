## 存疑之处

1. **181—195 年**：出生月份、父亲卒年、离开阳都的确切时间均无记载；南下豫章置于 194H2 是依据通鉴 195 年"朱皓攻玄"倒推。
2. **诸葛玄的结局**：本传说往依刘表后卒，《献帝春秋》说 197 年正月在豫章西城被杀，两说不能调和；行踪采本传，卒年借《献帝春秋》。
3. **隆中 vs 南阳卧龙岗**：采用襄阳隆中（《汉晋春秋》）。
4. **三顾茅庐在 207 年哪半年**无记载，置于 207H2。
5. **临烝→公安**的转移时间不明（209H1—211H1 置于临烝，211H2 起公安）。
6. **214 年入蜀路线**：通鉴记"溯流克巴东，至江州"；自江州到成都，张飞走巴西、德阳，赵云走江阳、犍为，亮本人路线未载，只标江州→成都。
7. **泸水渡口**、**赤阪**、**西县**、**建威**今址均无定论，坐标仅示意（low）。
8. **七擒七纵**（225H2）整步标为 traditional，但同一步中"秋平四郡、十二月还成都"是后主传明载——半年粒度下二者无法拆开。
9. **卤城之战**细节来自裴注引《汉晋春秋》，该步仍标 documented（祁山、木牛、六月退军见后主传）。
10. **《后出师表》**真伪有争议，未用作引文。
11. 卒年月据本传；卒地另有"郭氏坞"说；归葬定军山时间不详，234H2 末地点暂取定军山。
12. 演义情节（草船借箭、借东风、空城计、七星灯）均未写入 places 或 milestone，只在相关 note 中注明"演义情节，非史实"。
