# 朱元璋半年粒度人生轨迹（1328H2 — 1398H1）

- `steps.json`：140 个半年步，连续无缺；8 个阶段；16 个里程碑（importance=1 共 7 个）。
- `places.json`：33 个地点，坐标经 OSM Nominatim 核验。
- 生成脚本都在 `data/_build/`：
  - `zhuyz_fetch.py`：抓维基文库原文，缓存到 `cache/zhuyz/ws_*.txt`
  - `zhuyz_lunar.py`：农历干支日换算成公元日期（儒略历），`DATES` 表里列出了全部关键日期
  - `zhuyz_geocode.py`：Nominatim 查询，缓存到 `cache/zhuyz/nominatim/`
  - `zhuyz_places.py`：生成 places.json（当时称谓、今地名、可信度、考证说明）
  - `zhuyz_steps.py`：生成 steps.json，数据按阶段写在脚本里

重新生成：

```
python3 data/_build/zhuyz_geocode.py && python3 data/_build/zhuyz_places.py && python3 data/_build/zhuyz_steps.py
```

**日期换算**：用 `lunar_python` 把“农历月 + 干支日”逐日换算成儒略历。以下记载都能对上：生卒两个锚点；“閏三月甲戌朔”（1352-04-15）、“六月乙卯”（1355-07-10，《纪事本末》作“六月朔”），换算出来都是当月初一。有几个事件因为换算落到了相邻的半年：

| 事件 | 农历 | 换算结果 | 归入 |
|------|------|----------|------|
| 亲征婺州 | 至正十八年十二月 | 1358-12-31 起 | 1359H1 |
| 自武昌还应天 | 至正二十三年十二月丙申 | 1364-01-05 | 1364H1 |
| 汪广洋贬死 | 洪武十二年十二月 | 1380-01 | 1380H1 |
| 颁《大明律》 | 洪武六年闰十一月庚寅 | 1374-01-06 | 1374H1 |
| 赐李善长死 | 洪武二十三年五月乙卯 | 1390-07-06 | 1390H2 |
| 谕不许复立丞相 | 洪武二十八年六月己丑 | 1395-07-14 | 1395H2 |

**行程原则**：只有本纪写明“如、幸、自將、至自”的才算出行。平江之役由徐达指挥，太祖没有亲临，所以 1367H2 的里程碑放在应天。洪武年间除两次幸汴梁、两次幸中都外，都按常驻南京处理（inferred），event 写当时的主要政事。

**低可信度地点**：皇觉寺原址（暂用明皇陵坐标）。孤庄村、东乡、康郎山、左蠡、瓦梁垒、龙湾取乡镇或代表点，标为 medium。说法有分歧的问题见 `steps.json` 的 `contested`。
