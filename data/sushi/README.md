# 苏轼半年粒度人生轨迹（1037H1 — 1101H2）

- `steps.json`：130 个半年步，连续无缺；7 个阶段；16 个里程碑（importance=1 共 7 个）。
- `places.json`：61 个地点，坐标经 OSM Nominatim 核验。
- 生成脚本都在 `data/_build/`：
  - `sushi_fetch.py`：抓维基文库原文，缓存到 `cache/sushi/ws_*.txt`
  - `sushi_lunar.py`：农历换公历（儒略历）
  - `sushi_geocode.py`：Nominatim 查询，缓存到 `cache/sushi/nominatim/`
  - `sushi_places.py`：生成 places.json
  - `sushi_steps.py`：生成 steps.json，数据按阶段写在脚本里

重新生成：

```
python3 data/_build/sushi_geocode.py && python3 data/_build/sushi_places.py && python3 data/_build/sushi_steps.py
```

## 可信度分布

| confidence | 步数 | 占比 |
|------------|------|------|
| documented | 70 | 54% |
| inferred | 60 | 46% |
| traditional | 0 | 0% |

inferred 主要来自两类：
- 眉山少年期（1037–1055）共 38 步，其中 36 步标为 inferred（多数无行程记载，1047、1054 两步只知年份）；
- 在任所、谪所期间没有出行记载的半年，包括凤翔、黄州、元祐汴京、惠州、儋州。

## 地点坐标

- 城市一律取今行政区的 Nominatim 结果（relation 或 node）。
- 褒斜道取南口石门（今石门水库）；大庾岭取梅关古道；庐山取牯岭镇。这三处的 confidence 标为 medium 或 high，见 places.json 的 note。
- 宋泗州城已没入洪泽湖，取盱眙县；濠州治钟离在凤阳临淮关一带，取凤阳县。这两处都标为 medium。

## 存疑之处

1. **1066H2 护丧归蜀的路线**：只知道是官船、自汴入淮溯江西归，具体停留地点没有记载。半年末的位置取江陵，属于推定。
2. **1068H2–1069H1 离蜀还朝的路线**：没有记载，只标出眉山和汴京。
3. **1089H1 赴杭的路线**：未见明载，半年末保守地放在汴京。
4. **1094H1 南迁**：查注收有《临城道中作》《子由新修汝州龙兴寺吴画壁》，可证途经临城、汝州。公历 6 月底的确切位置不明，取汝州。
5. **1056 年出川路线**：S6 是转引，没能读到王文诰原书。
6. **以下日期只来自维基百科（S7），没有一手史料核对**：
   - 王闰之卒年（1093）
   - 1054 年娶王弗
   - 1070 年考官事
   - 1096 年修桥
   - 1099 年姜唐佐从学
   - 1101 年“孙氏馆”
7. **任务书的提示与史料不符**：
   - 任务书说北归“经永州一带”，但苏轼实际没有到永州，途中就改为提举玉局观、任便居住。数据按查注取廉州—藤州—广州—韶州。
   - 维基百科说“熙宁八年除夕在润州”，与查注卷十一“除夜野宿常州城外”（熙宁六年）不合，数据采用查注。
8. **引文是跨时期配用的**，各条已在 quote.source 中注明写作时间：
   - 《江城子·记梦》作于 1075 年，配在王弗卒（1065H2）；
   - 《饮湖上初晴后雨》作于 1073 年，配在苏堤（1090H1）；
   - 《食荔支》大约作于 1096 年，配在到惠州（1094H2）。
9. **《念奴娇·赤壁怀古》文本有分歧**：通行本作“浪淘尽”，《容斋随笔》引黄庭坚手书本作“浪声沉”。因此赤壁里程碑的 quote 改用《赤壁赋》。
